# Font sources

Archivo and Manrope from official `@expo-google-fonts/archivo@0.4.2` and `@expo-google-fonts/manrope@0.4.2`. Font binaries ship locally from npm packages and are loaded through expo-font. Both font licenses are SIL Open Font License 1.1; the adjacent license texts retain copyright and reserved-name terms. Package generator code is MIT. No third-party font CDN or proprietary brand font is used.

Upstream: https://github.com/google/fonts/tree/main/ofl/archivo and https://github.com/google/fonts/tree/main/ofl/manrope.
