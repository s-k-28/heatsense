# HeatSense handoff

The maintained project layout and commands are in [README.md](README.md) and the [documentation index](docs/README.md).

- Repository: `s-k-28/heatsense`; publish verified changes to `main`, then mirror to `cac-dev`.
- Expo SDK57. Read the versioned Expo documentation specified by AGENTS.md before editing Expo code.
- UI components are grouped under `src/components/`; routes remain under `src/app/`. See the [architecture guide](docs/engineering/architecture.md).
- Use local Firebase emulators for test identities and readings. Keep private environment files and local session history out of commits.
- Preserve existing user changes, especially `AGENTS.md` and `ios/Podfile.lock`; do not stage unrelated edits.
- Verify with `npm run typecheck`, `npm run lint`, `npm run check:unused`, `npm run check:docs`, and `npm run test:logic`. Build platform bundles after import or asset changes.
- Keep commit and PR attribution limited to human contributors; project Claude settings suppress generated bylines.

Historical records: [October23 handoff](docs/archive/handoff-2026-10-23.md), [native walkthrough](docs/design/audits/rundown-2026-10-23.md). Their old code paths and UI descriptions reflect the versions inspected.
